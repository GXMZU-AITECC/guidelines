# 权限四档与保密

组织默认对所有仓库零权限：**能看见什么完全取决于进了哪个 team**，没有"入社了就全都能看"这回事。看不到某个仓，就是没进对应 team，别去打听别人的私有仓。

| 层级 | team | 范围 |
| :--- | :--- | :--- |
| 组织管理员 | — | 组织设置、建仓删仓、建 team、指派 Reviewer、执行处分 |
| 项目负责人 | 该项目 team（`unitree-go2`、`yundrone`、`zhilian-cyber`、`unitree-g1-rl`） | 只管自己这一个仓：可写、可合并 |
| 评审人 | `reviewers` | 训练场的评审、批准、合并 |
| 新人 | `rookies` | 训练场、`qq-auto-bot`、`unitree-g1-demo`、成员主页，只读 |

**申请路径**：新人过考核 → 管理员拉进 `rookies`；要进项目 → 找项目负责人，由负责人报管理员加进该项目 team；Reviewer 由社长指派，不接受自荐。文档、模板、代码注释里一律写 team 名，不写个人账号——换届只改 team 成员。

**保密**：组织下所有仓库的全部内容（源码、文档、设备资料、赛题、Issue 与 PR 讨论）都是社团内部资产，无论仓库技术上是否对外可见；考核期间接触到的同样适用。外传即 P0。
